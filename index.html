Envelope Check

Free, plain-English cyber security tools for small charities and businesses. Everything runs in your browser.

Follow a fake email sent in your name.

See how your domain's public settings would treat a forged email, spot lookalike domains, and get a fix plan you can follow or pass to your IT provider. No email is sent.

Use the part after the @ in your email address. We only read public DNS records.

Is this link safe to open?

Paste a link from an email or message and we'll point out common warning signs. We read the link's text only - we never open it.

Don't type passwords or personal details here - just the link.

Is this file dangerous?

Check a file against VirusTotal's database of known malware. Your file never leaves your device - only its fingerprint is looked up.

We read the file only to work out its fingerprint (a SHA-256 hash) in your browser. Nothing is uploaded by this tool.

Password tools

Create strong passwords, and check whether a password has turned up in a known data breach - without it ever leaving your device.

Has a password been breached?

Your password never leaves your device. Only a short, scrambled fingerprint of it is sent, which can't be reversed. Still, don't check a password you're about to keep using - test ones like it instead.
